### 4b — Rubric

**Criterion 1 — External Stylesheet Created & Implemented (10 marks)**

- **Full (10):** External stylesheet exists, correctly linked across the website, evidence provided.
- **Partial (8–9):** Linked correctly, minor implementation uncertainty.
- **Low (5–7):** Partial linking, some pages likely not connected.
- **Minimal (1–4):** Stylesheet exists but implementation questionable.
- **Zero (0):** No external stylesheet, no evidence available.

**Special case:** If CSS is embedded inside `<style>` tags instead of an external stylesheet, heavily reduce this mark. A single-page HTML file with embedded CSS should not receive high marks here.

*(Additional criteria from the original rubric are assumed for this example. In a real submission, all 11 criteria would be listed with full guidance.)*
